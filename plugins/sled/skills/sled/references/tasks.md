# Задачи из протокола

Порядок: задачи ставит ИИ сам — только там, где это надёжно и безопасно (Битрикс24 из Claude Code).
Во всех остальных случаях ИИ выдаёт готовый список, а человек заводит задачи сам — это
2–3 минуты на встречу.

Общее правило для любой системы: сначала точный нумерованный список (что, кому, срок, куда),
потом «да» от пользователя, и только потом запись. Ставишь ровно подтверждённые пункты.

## Почему браузерный чат не ставит задачи в Битрикс24 сам

Битрикс24 принимает задачу по ссылке входящего вебхука — методом `tasks.task.add`, в который
передаются название, ответственный и срок. В браузерном чате ИИ может только **открыть ссылку,
которую ты прислал, ровно как есть**:
- Claude открывает только ссылки, которые уже были в переписке (в твоих сообщениях или
  в результатах поиска), и не открывает ссылку, которую сам составил. Ссылку с ключом внутри
  он откроет, только если ключ был в твоём сообщении. Отправить данные (запрос POST)
  через чтение страниц нельзя — только прочитать страницу.
- ChatGPT и DeepSeek: как они открывают ссылки и могут ли отправлять данные, в официальной
  справке не описано — не рассчитываем на это.

Значит, чтобы чат поставил задачу, тебе пришлось бы самому собрать ссылку с текстом каждой
задачи — это дольше, чем завести задачу руками. Поэтому в браузерном чате:
**ИИ готовит список → ты заводишь задачи сам.** Не присылай в браузерный чат ссылку вебхука
на задачи — она там не нужна.

Ещё один обход — запуск кода в Claude с доступом в интернет («Allow network egress» →
«All domains»). Anthropic называет этот режим самым рискованным, а ключ вебхука при этом
окажется в переписке. Мы его не используем и не советуем.

## Готовый список для ручного ввода (любой чат, любая система)

Для каждой подтверждённой задачи выдай отдельный блок:

```
Задача 1
Название: Отправить КП клиенту «Ромашка»
Ответственный: Иван Петров
Срок: 29.10.2026 18:00
Описание: Из встречи 27.10.2026 «Планёрка отдела продаж». Решение: пилот на 2 недели.
```

Подскажи, куда вставить:
- Битрикс24: «Задачи и проекты» → «Создать» → название, «Ответственный», «Крайний срок».
- amoCRM, Яндекс Трекер, Kaiten, Планфикс и другое — так же, через кнопку создания задачи.

## Битрикс24 из Claude Code — задачи ставит ИИ

Claude Code (программа для работы с Claude на компьютере) умеет отправлять запросы сам.
Задачи ставит скрипт `scripts/sled.py` из этого навыка: он знает только один метод —
`tasks.task.add` (создать задачу), сам читает ссылку вебхука из файла на твоём компьютере
и никогда её не печатает.

### Настройка — один раз

1. **Отдельный сотрудник.** Лучше завести отдельного сотрудника для ИИ, например «ИИ-постановщик».
   Вебхук работает с правами того, кто его создал, и задачи будут от его имени (он — постановщик).
   Если отдельного сотрудника завести нельзя — создавай вебхук под собой, но ограничь права (шаг 3).
2. **Входящий вебхук.** Зайди под этим сотрудником. «Приложения» → «Разработчикам» → вкладка
   «Готовые сценарии» → «Другое» → «Входящий вебхук». Если пункта нет — создание вебхуков
   закрыл администратор («Настройки» → «Настройки Битрикс24» → «Безопасность» →
   «Интеграции Битрикс24» → «Кому разрешить создавать входящие вебхуки»).
3. **Права — только «Задачи» (`task`).** Никаких «CRM», «Пользователи» и других разделов.
   Это **отдельный** вебхук: не используй ссылку для чтения CRM из капсулы «Пульс» — у неё
   другие права, и смешивать их нельзя.
4. В генераторе запросов **не нажимай «Выполнить»** с методом создания задачи — это создаст
   тестовую задачу. Просто нажми «Создать» (или «Сохранить») и скопируй ссылку вебхука вида
   `https://<портал>.bitrix24.ru/rest/<номер>/<ключ>/`.
5. **Положи ссылку в файл — не в чат.** Создай в своей домашней папке файл
   `.config/sled/b24_webhook` (на Windows — `C:\Users\<имя>\.config\sled\b24_webhook`)
   и вставь в него ссылку одной строкой. Так ссылка не попадёт в переписку с ИИ.
   Другой вариант — переменная окружения `SLED_B24_WEBHOOK`.
6. **Номера сотрудников.** Открой профиль сотрудника в Битрикс24: число в адресе
   `.../company/personal/user/15/` — его номер. Впиши в «Настройки следа»: «Иван Петров — 15».
7. **Проверка.** Попроси: «поставь тестовую задачу себе на завтра». ИИ покажет её, ты
   ответишь «да», задача появится в Битрикс24. Потом удали её сам в Битрикс24.

### Как ИИ ставит задачи (каждый раз)

1. Сохраняет протокол в файл и собирает список задач:
   `python3 scripts/sled.py parse protocol.md --people people.json --tz +05:00 --default-time 18:00 > tasks.json`
   (`people.json` — имена и номера из настроек; `--tz` — твой часовой пояс).
2. Показывает список без отправки: `python3 scripts/sled.py b24 tasks.json` — это только
   просмотр, в Битрикс24 ничего не уходит.
3. Ждёт твоего «да». Затем: `python3 scripts/sled.py b24 tasks.json --confirm`
   (или `--only 1,3` — номера строк из таблицы «Задачи», если подтвердил не всё).
4. Отчитывается номерами созданных задач. Результат по каждой задаче скрипт хранит рядом
   со списком (файл `tasks.sent.json`): повторный запуск не создаст ту же задачу дважды,
   а если связь оборвалась посреди отправки или Битрикс24 ответил непонятно — скрипт
   остановится и попросит проверить задачу в Битрикс24. Два запуска одновременно скрипт
   не допускает.

Если скрипт написал, что у задачи нет ответственного или срока, — ИИ спрашивает тебя, а не
угадывает.

### Безопасность

- Ссылка вебхука — это ключ: кто её знает, тот ставит задачи от имени этого сотрудника.
  Не пересылай её и не вставляй в чат. Если ссылка всё же попала в чат или к постороннему —
  удали вебхук в Битрикс24 и создай новый.
- Скрипт вызывает только `tasks.task.add` и только с флагом `--confirm`. Изменения, закрытия
  и удаления задач в капсуле нет.
- Права вебхука — только «Задачи». Даже если кто-то попросит ИИ «поменять сделку», вебхук
  этого не позволит.

## amoCRM, Яндекс Трекер, Kaiten и другие

Без своего сервера надёжного пути для браузерного чата не нашли — готовый список задач
и ручной ввод. Справочно:
- Официального подключения amoCRM к Claude или ChatGPT мы не нашли (не подтверждено).
- У Яндекс Трекера есть официальный сервер подключения для ИИ, но в браузерном Claude
  не подтверждено, что ему можно передать нужные ключи; в ChatGPT свои подключения
  с записью есть только на тарифах Business и Enterprise.

  https://apidocs.bitrix24.ru/local-integrations/local-webhooks.html

  с ключом — только из сообщения пользователя:
  https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool и
  https://support.claude.com/en/articles/13455879
- Claude, доступ кода в интернет («All domains» — самый рискованный режим):
  https://support.claude.com/en/articles/12111783
- ChatGPT, свои подключения с записью — Business и Enterprise:
  https://help.openai.com/en/articles/12584461
- Яндекс Трекер, сервер подключения для ИИ: https://yandex.ru/support/tracker/ru/user/mcp-server

Не подтверждено: путь «Создать» в генераторе вебхука без тестового запуска (в справке описан
формат ссылки, а не экран); как ChatGPT и DeepSeek открывают ссылки; подключение amoCRM
и Яндекс Трекера в браузерных чатах.
